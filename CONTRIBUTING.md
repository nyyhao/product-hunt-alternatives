# Contributing

Thanks for helping keep this list useful.

## Adding a directory

1. The site must be live, accept submissions, and be in English.
2. Add it to the section that fits best, using this format:

   ```markdown
   - [Name](https://example.com/) - One short sentence on what it is and who it is for.
   ```

3. Keep the description factual. No "best", "#1" or pricing claims.
4. One directory per pull request.

## Removing a directory

If a link is dead, has stopped accepting submissions, or has turned into spam, open an issue or a pull request that removes it.
